# Bundled screenshot sources

These compressed WebP files are used as optional illustrations in Potts Help Centre articles.

## Official webtrees images

- `interactive-tree.webp` — official webtrees homepage pedigree illustration, sourced from `https://webtrees.net/assets/img/tree-mock-screen.png`.
- `facts-and-events-place.webp` — official webtrees location guide, sourced from `https://webtrees.net/faq/mk-facts.png`.
- `event-map.webp` — official webtrees location guide, sourced from `https://webtrees.net/faq/mk-map-1.png`.
- `edit-location.webp` — official webtrees location guide, sourced from `https://webtrees.net/faq/mk-location.png`.

## Potts Help Centre illustrated guides

- `quick-search-guide.webp`
- `individual-tabs-guide.webp`
- `sign-in-guide.webp`
- `add-partner-guide.webp`
- `add-child-guide.webp`
- `edit-name-guide.webp`
- `media-upload-guide.webp`
- `source-citation-guide.webp`

Files ending in `-guide.webp` are original annotated illustrations created for Potts Help Centre using fictional names and records. They are not captures of a private family tree. They show the general location and purpose of controls while acknowledging that themes, access permissions, languages and enabled modules can change the actual screen.

All files are compressed as WebP for efficient delivery. Article captions, alternative text and source labels explain what each image represents.

Licensing and attribution details are also recorded in the module-level `NOTICE.md`.
