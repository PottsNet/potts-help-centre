# Potts Help Centre 1.0.0-rc.1

This is the first release candidate for the public 1.0.0 release.

## What it provides

- one searchable help centre for visitors and registered members
- audience-specific Quick help and topic browsing
- 71 editable starter articles
- contextual help for common webtrees pages and editing tasks
- optional module-aware articles for supported Potts modules
- feedback reporting and article-review indicators
- twelve accessible illustrated guides
- theme-aware desktop, tablet and phone layouts

## Upgrade safety

The public name and GitHub repository are now **Potts Help Centre** and `potts-help-centre`. The installation folder, namespace and storage identity remain `potts_member_help`, so existing articles, settings and feedback are retained.

## Installation asset

Attach `potts_help_centre_v1.0.0-rc.1.zip` to the GitHub release and mark the release as a **pre-release**.

Users should install the named asset rather than GitHub’s automatically generated source archives.

## Before 1.0.0

Complete `TESTING.md`, particularly the upgrade, clean-install, privacy, standard-theme and mobile checks. Resolve any release-blocking issue before changing the version to 1.0.0.
